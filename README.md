# Balkrishna Boys PG - Official Website

Landing page and web portal for **Balkrishna Boys PG** in Ahmedabad (near Sola Railway Crossing & Science City Road). Designed for high-conversion lead generation on GitHub Pages with zero server backend.

## 🚀 Live Demo & Deployment

- Instant mobile responsiveness, SEO optimized with Schema.org `Hostel` structured data.

## ⚙️ Quick Customization Guide for Owner

### 1. Update Monthly Rates
Open [index.html](file:///e:/balkrishnaboyspg.github.io/index.html) and search for `Dummy Rate`. Update the placeholder rates:
- **2 Sharing:** `₹8,500` (Non-AC, General Bath)
- **3 Sharing:** `₹7,000` (Non-AC) / `₹8,000` (AC, Attached Bath)
- **4 Sharing:** `₹6,000` (Non-AC) / `₹7,000` (AC, Attached Bath)
- **5 Sharing:** `₹5,200` (Non-AC, 1 Exclusive Room)

### 2. Update Contact & WhatsApp Number
1. In [assets/js/main.js](file:///e:/balkrishnaboyspg.github.io/assets/js/main.js), update `PG_CONFIG.whatsappNumber` to the owner's phone number with country code (e.g., `919876543210`).
2. In [index.html](file:///e:/balkrishnaboyspg.github.io/index.html), search for `9876543210` and replace with the owner's calling/WhatsApp number.

### 3. Enable Email Inquiries (Zero Backend)
1. Visit [Web3Forms](https://web3forms.com) and get a free access key sent to your email.
2. In [assets/js/main.js](file:///e:/balkrishnaboyspg.github.io/assets/js/main.js), replace `YOUR_WEB3FORMS_ACCESS_KEY_HERE` with your access key.

### 4. Enable Live Google Maps Reviews Widget (Optional)
1. Create a free Google Reviews widget at [Elfsight](https://elfsight.com) or [Trustmary](https://trustmary.com).
2. Paste the widget script tag at the bottom of [index.html](file:///e:/balkrishnaboyspg.github.io/index.html). The page already has verified static review fallbacks if the widget is not used.
